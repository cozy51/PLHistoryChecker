# ユニット接続実績チェッカー

今回物件のユニット接続について、2つのPLが同一の過去物件キー内で使用された実績を確認するPC向けWebアプリです。

> 「実績あり」は同一過去物件内で両PLが使用されたことを意味します。両ユニットが直接接続されていたことは保証しません。

## 起動方法

Node.jsをインストールした環境で実行します。PowerShellの実行ポリシーで`npm`が拒否される場合は`npm.cmd`を使用してください。

```shell
npm.cmd install
npm.cmd run dev
```

本番用ファイルの生成とテストは次のコマンドです。

```shell
npm.cmd test
npm.cmd run build
```

## CSV形式

CSVはUTF-8を推奨します。値の前後の空白は取り込み時に除去されます。

## 今回物件をクリップボードから取り込む

「今回物件」画面では、CSVファイルを作成せず、Excelのセル範囲をコピーして直接取り込めます。

1. Excelで「ユニットNo・PL」の2列を選択してコピーします。
2. 「クリップボードから取り込む（置換）」を押します。

ユニットNoとユニット名はアプリ内の固定マスターで管理されるため、ユニット名の入力は不要です。見出し行はあってもなくても構いません。見出しがある場合は列順も変更できます。取り込みを実行すると、現在のPLはクリップボードの内容で置き換わります。ブラウザからクリップボードへのアクセス確認が表示された場合は許可してください。

## 接続組み合わせ

接続No、ユニットNo_A、ユニットNo_Bの36件は、`src/data/connectionMaster.ts`の固定接続マスターで管理します。IndexedDBには接続情報を保存しません。

接続判定画面での取り込み操作は不要です。ユニット名_A、PL_A、ユニット名_B、PL_Bは、固定ユニットマスターと今回物件PLから自動取得します。

### 今回物件.csv

```csv
ユニットNo,PL
1,HH11000010
2,HH11103B10
```

### 実績物件.csv

```csv
物件コード,客先名
95742,Sample Customer
```

### 実績物件PL.csv（横持ち）

```csv
ユニットNo,95742_001,95175_001
1,HH11002010,HH11001010
2,HH11104B10,HH11104B10
```

2列目以降の見出しを物件キーとして縦持ちレコードへ変換します。ユニット名はユニットNoをキーに、アプリ内の固定ユニットマスターから取得します。CSVへのユニット名入力は不要です。固定マスターにないユニットNoと空のPLセルは警告対象となり、登録されません。

実績データ管理画面では、実績物件と実績PLのどちらもCSVのほか、Excelで同じ形式の範囲をコピーしてクリップボードから直接取り込めます。実績物件のクリップボード取込は見出し行があってもなくても構いません。見出しなしの場合は、左から「物件コード、客先名」の順でコピーしてください。取込方法の初期値は「追加」です。「追加」では既存データを維持し、同じ物件コードまたは同じ実績PLレコードは更新します。

実績PL一覧の客先名は、物件キーの先頭5文字と実績物件の物件コードを照合して表示します。

## データ保存と性能

- データベース名: `UnitConnectionHistoryDB`
- 保存先: ブラウザのIndexedDB
- 今回物件のユニットNo・ユニット名は`src/data/unitMaster.ts`の固定マスターです。
- 接続No・ユニットNo_A・ユニットNo_Bは`src/data/connectionMaster.ts`の固定マスターです。
- IndexedDBの`currentPLs`には固定マスターのIDと今回物件のPLだけを保存し、ユニットNo・ユニット名は保存しません。
- 旧バージョンで登録済みの今回物件PLは、初回起動時に新しい保存形式へ自動移行します。
- ブラウザを閉じてもデータは保持されます。
- ブラウザ、ブラウザプロファイル、PCが異なる場合はデータを共有しません。
- 実績PLの判定は`pl`インデックスを使用し、通常処理で全件を取得しません。
- 実績PL CSVは1行ずつ解析し、最大1,000件単位で`bulkPut`します。
- 実績PL一覧は100・500・1,000件単位のページングです。
- 同一PL組み合わせの判定結果は画面セッション中にキャッシュされます。
- 実績PLの追加・置換・削除後は判定キャッシュが破棄されます。

## 注意事項

- IndexedDBを削除するブラウザ設定やサイトデータ削除を行うと、登録データも削除されます。
- 実績PLの「置換」は既存の実績PLを削除してから新しいCSVを登録します。
- 大量取り込み中はタブを閉じないでください。

## 一覧からの削除

今回物件、実績物件、実績PLの各一覧には、右端に操作列があります。削除前に対象内容を表示して確認します。

- 今回物件の固定ユニット行は削除されません。「PLクリア」で対象ユニットのPLだけを空欄にできます。
- 接続判定はアプリ内の固定接続マスターのため、行の削除はできません。
- 実績物件を削除しても、物件コードに対応する実績PLは削除されません。
- 実績PLを削除すると判定キャッシュが破棄され、次回の接続判定に反映されます。
